# Unsupervised_Learning_Model_Evaluation
End-to-end Machine Learning project exploring K-Means and Hierarchical Clustering, Elbow Method, Silhouette Score, PCA dimensionality reduction, Logistic Regression, Confusion Matrix, Precision, Recall, F1-Score, ROC-AUC, Cross-Validation, and GridSearchCV hyperparameter tuning using Python and Scikit-learn.
